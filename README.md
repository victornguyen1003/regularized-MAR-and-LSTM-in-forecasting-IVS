# Parametric-and-Non-parametric-Models-in-Option-Pricing-for-High-Liquidity-Cryptocurrencies

- Estimate static volatility surfaces by extracting raw implied volatility via Newton-Raphson algorithms and fitting OLS and Series Regressions, optimized using AIC and K-Fold CV
- Construct a Regression Tree time-series forecasting pipeline that is hypothesized to outperform the Black-Scholes baseline, validating with out-of-sample MSE and bootstrapped 95% confidence intervals
